THE FILE THAT TUNES EVERYTHING

the pick chain

WHERE THE FILE IS FOUND

Three stops, in order - and a hard fall-through when none of them exists (docs/config/aphrodite-toml.md, "File location"):

1  APHRODITE_CONFIG_PATH  — explicit override. A path that does not exist still counts as set: it falls through to CLI-flag mode, it never silently redirects.
2  ./aphrodite.toml  — the default: the current working directory.
3  ~/.hermes/aphrodite/aphrodite.toml  — the fallback, consulted only when the env var was NOT set; this is where aphrodite setup writes its generated config.
4  none found  — CLI-flag mode: a single proxy, --mode / --listen / --api-key and friends.

two stacks

ONE FILE, TWO PARSERS

THE RUST HTTP PROXY

config/proxy.rs, active whenever an aphrodite.toml is found. It reads [[proxies]], [defaults], the four hot-reload thresholds in [compression], and [previews] preview_max_chars. For every field except api_key, mode and listen: env var → TOML (per-proxy entry → [defaults]) → compiled-in default.

THE HERMES DYLIB SESSION

config_loader.rs, read once at dylib load: the engine/chain-split/poll keys in [compression], [defaults] model / api_url, [flow] budget_chars, [directives] active, [prompts] session_inject. The FFI runtime-override variant is the aphrodite_config_get / aphrodite_config_set pair on the C-ABI bridge - values surfaced and changed mid-session, while the standalone HTTP proxy never reads the dylib-only keys.

the pair

[[PROXIES]] - CACHE :9797 + TOKEN :9798

cache · 127.0.0.1:9797

mode "cache" - the in-memory backend, threshold 8192 bytes compiled-in (the example lowers it to 4096). tool_relay = true enables the /tool/relay endpoint.

token · 127.0.0.1:9798

mode "token" - the SQLite-backed durable store, threshold 1024 compiled-in (the example lowers it to 512), TTL from ccr_ttl_seconds.

WARNING - THE 0.0.0.0 LINES

Listeners bind loopback-only by default, and the router rejects non-loopback peers (and non-loopback Host headers) on every route except /health. Uncommenting listen = "0.0.0.0:..." exposes an unauthenticated listener to your LAN: /retrieve, /history and /ccr/* have no authentication of their own.

hot-reload

[COMPRESSION] - THE KNOBS

POST /reload

per-turn context

[FLOW] / [DIRECTIVES] / [PREVIEWS]

[FLOW]

budget_chars = 2600 - the hard cap on ALL per-turn injected context (directives + nudges + recall catalog + retrieve hint). Sections drop bottom-up when over budget; directives and nudges never drop. Dylib only; env: APHRODITE_FLOW_BUDGET_CHARS.

[DIRECTIVES]

active = ["focus", "foresight"] - which loaded directives start active; swap mid-conversation via aphrodite_directive. Names not in the loaded set are silently filtered; an empty list seeds focus + foresight + lazy. Built-in set: focus, foresight, ccr-handling, cleanup, explore, lazy, lazy-eval.

[PREVIEWS]

preview_max_chars = 120 - caps the whole rendered preview string, not per line; 0 = unlimited. Env APHRODITE_PREVIEW_MAX_CHARS > TOML > unlimited. Re-applied by POST /reload.

honest ledger

DOCUMENTED BUT UNWIRED

These keys parse cleanly but nothing in the current codebase reads them back out - setting one is a silent no-op. They are kept and marked for forward compatibility; the shipped example labels each one in place.

auto_expand auto_expand_limit catalog_mode classifier_poll previews.model_family previews.code_structure_map prompts.retrieve_guidance prompts.ccr_marker_hint prompts.catalog_intent_hints

No parser home at all - compression.prefetch and the old [templates.*] sections were removed from the shipped files; marker and preview formats are compiled into the binary.

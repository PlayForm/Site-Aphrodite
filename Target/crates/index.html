CRATES // WORKSPACE MANIFEST

Crates

Two workspace crates plus the vendored Headroom fork that carries the content transforms. It is the reason the fork stays separate: Aphrodite adds the preview pipeline, CCR storage, Hermes integration, and dual-proxy architecture on top of Headroom, instead of rewriting the transforms. SRC: README.md:515-519

#01 // PROXY CRATE

aphrodite

v1.6.6

Chat Completions proxy with CCR, tool relay, and programmatic CCR for Hermes agent integration. Ships the aphrodite binary and a cdylib/rlib library; built on axum and tokio.

INSTALL // CARGO:
$ cargo install aphrodite
<<<CCR:crate.aphrodite|1.6.6|axum-0.8.9+tokio-1.53.1>>>

SRC: crates/aphrodite/Cargo.toml

#02 // INTEGRATION CRATE

aphrodite-hermes

v1.6.6

Hermes Agent-specific integration for the Aphrodite compression engine - tool schemas, hook dispatch, skill registration. Ships the aphrodite-hermes-setup helper binary and the dylib; watches config with notify.

INSTALL // CARGO:
$ cargo install aphrodite-hermes

SRC: crates/aphrodite-hermes/Cargo.toml

CONFIGURATION SURFACE // APHRODITE.TOML.EXAMPLE
[[proxies]]
cache → 127.0.0.1:9797 timeout 120
token → 127.0.0.1:9798 timeout 300
tool_relay = true (both)
[defaults]
api_url = "https://api.openai.com"
ccr_ttl_seconds = 3600
[flow]
budget_chars = 2600
[compression]
engine_threshold_pct = 45
tool_threshold_token = 512
tool_threshold_cache = 4096
terminal_threshold = 1024
inline_threshold = 2048
code_multiplier = 3.0
auto_reload = false # opt-in
[previews]
preview_max_chars = 120

Keys not yet wired into the runtime are annotated DOCUMENTED BUT UNWIRED in the example; the dead [templates.*] subtree was removed in v1.6.6. Marker grammar: <<<CCR:hash|type|size>>>

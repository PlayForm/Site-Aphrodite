Crates

Two workspace crates plus the vendored Headroom fork that carries the content transforms. Aphrodite adds the preview pipeline, CCR storage, Hermes integration, and dual-proxy architecture on top of Headroom.

aphrodite v1.6.6

Chat Completions proxy with CCR, tool relay, and programmatic CCR for Hermes agent integration. Ships the aphrodite binary and a cdylib/rlib library; built on axum and tokio.

aphrodite-hermes v1.6.6

Hermes Agent-specific integration for the Aphrodite compression engine - tool schemas, hook dispatch, skill registration. Ships the aphrodite-hermes-setup helper binary and the dylib; watches config with notify.

Configuration surface

From aphrodite.toml.example - the main sections:

  • [[proxies]] - named listeners; the two defaults are cache on 127.0.0.1:9797 (timeout 120) and token on 127.0.0.1:9798 (timeout 300), both with tool relay on.
  • [defaults] - api_url, model, ccr_ttl_seconds (3600), optional api_key.
  • [compression] - the engine thresholds (engine_threshold_pct 45, protect-first 2 / protect-last 5, min 8 messages), the type multipliers (code ×3), the context engine toggle, polling worker, opt-in auto-reload, and chain splitting.
  • [previews] - preview rendering options; preview_max_chars 120.
  • [prompts] - retrieval guidance and the session_inject CCR notice.
  • [directives] - the active directive list (seeding focus and foresight).
  • [flow] - budget_chars, the hard cap for all per-turn injected context (2600).

Keys not yet wired into the runtime are annotated DOCUMENTED BUT UNWIRED in the example; dead sections ([templates.*]) were removed in v1.6.6.

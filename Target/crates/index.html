CRATES // WORKSPACE MANIFEST

Crates

Two workspace crates plus the vendored Headroom fork that carries the content transforms. It is the reason the fork stays separate: Aphrodite adds the preview pipeline, CCR storage, Hermes integration, and dual-proxy architecture on top of Headroom, instead of rewriting the transforms. The binary links the fork's headroom-core library only, published as aphrodite-headroom-core v0.2.1: upstream's proxy surface does not ship in Aphrodite. SRC: README.md:515-519

#01 // PROXY CRATE

aphrodite

v1.8.1

Chat Completions proxy with CCR, tool relay, and programmatic CCR for Hermes agent integration.

Ships the aphrodite binary and a cdylib/rlib library; built on axum and tokio.

INSTALL // CARGO:
$ cargo install aphrodite
<<<CCR:crate.aphrodite|1.8.1|axum-0.8.9+tokio-1.53.1>>>

SRC: crates/aphrodite/Cargo.toml

#02 // INTEGRATION CRATE

aphrodite-hermes

v1.8.1

Hermes Agent-specific integration for the Aphrodite compression engine - tool schemas, hook dispatch, skill registration.

Ships the aphrodite-hermes-setup helper binary and the dylib; watches config with notify.

INSTALL // CARGO:
$ cargo install aphrodite-hermes

SRC: crates/aphrodite-hermes/Cargo.toml

CONFIGURATION SURFACE // APHRODITE.TOML.EXAMPLE
[[proxies]]
cache → 127.0.0.1:9797 timeout 120
token → 127.0.0.1:9798 timeout 300
tool_relay = true (both)
[defaults]
api_url = "https://api.openai.com"
ccr_ttl_seconds = 3600
[flow]
budget_chars = 2600
[compression]
engine_threshold_pct = 30
tool_threshold_token = 256
tool_threshold_cache = 2048
terminal_threshold = 256
inline_threshold = 1024
code_multiplier = 1.0
auto_reload = true # shipped default
[previews]
preview_max_chars = 0

Keys without a live consumer are annotated DOCUMENTED BUT UNWIRED in the example; the [templates.*] section is live configuration - preview families, the marker block, prompt templates and the reverse key map render from these format strings (hardcoded builders apply when a block is absent).

Marker grammar: <<<CCR:hash|type|size>>>

SRC: aphrodite.toml.example; CHANGELOG.md v1.8.1

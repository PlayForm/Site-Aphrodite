03 // THE PIPELINE 04 / 11

Four steps, one decision.

Classify, preview, store, decide. The whole compress step stays under a millisecond.

01 // STAGE Classify 40-123 ns type-aware, first match wins
02 // STAGE Preview ~15 tokens the enriched line, not the blob
03 // STAGE Store BLAKE3 SQLite :9798, memory :9797
04 // STAGE Decide on demand aphrodite_retrieve(hash)
one output one marker sub-millisecond compress no API round-trip
04 // STEP 1 - CLASSIFY 05 / 11

The classifier is the gate.

One type per invocation, first match wins. Each type carries its own threshold, so an error stays visible while a build log gets squeezed.

07 // STEP 4 - DECIDE 08 / 11

08 // THE HOOKS 09 / 11

Six hooks, one turn.

The plugin is a ctypes shim over a Rust dylib. Hermes calls it at every seam, so the intercept lands before the model sees anything.

H1 on_session_start resets per-session state
H2 pre_tool_call backgrounds slow calls, splits chains
H3 transform_tool_result every tool result becomes a marker
H4 transform_terminal_output shell output becomes a marker, exit code kept
H5 pre_llm_call directives, nudges, recall under 4,000 chars
H6 post_llm_call archives the turn, advances the counter
6 hooks registered 13 tools in namespace ctypes shim -> rust dylib 4,096 / 1,024 char gates

SETUP // BINARY ACQUISITION

Setup

Aphrodite ships as a Hermes Agent plugin (recommended) or a standalone Chat Completions proxy. Both install paths land on this page - and the full host map, including the flavors still planned, is laid out on FLAVORS. Binaries are never shipped in the repository and register() never downloads - run the explicit setup step to fetch the binary and dylib from GitHub Releases into ~/.hermes/aphrodite/, with SHA-256 verification.

#A // HERMES PLUGIN (RECOMMENDED)

Clone, link, download, enable

6 STEPS
$ git clone https://github.com/PlayForm/Aphrodite-Hermes.git
$ cd Aphrodite-Hermes
$ ln -s "$(pwd)" ~/.hermes/plugins/aphrodite
$ bash download.sh // or: pwsh ./download.ps1 (Windows)
$ cd ..
$ hermes plugins enable aphrodite
$ hermes
OUTCOME // VERIFIED INSTALL:
Binary + dylib fetched from GitHub Releases, SHA-256 verified, plugin enabled.
#B // CARGO

Crates.io install

$ cargo install aphrodite // proxy binary
$ cargo install aphrodite-hermes // dylib + helper bin
$ aphrodite setup
// runtime home under ~/.hermes/aphrodite + hooks-only loader
#C // FROM SOURCE

Build it yourself

$ git clone https://github.com/PlayForm/Aphrodite.git
$ cd Aphrodite
$ git submodule update --init --recursive
$ cargo build --release -p aphrodite -p aphrodite-hermes
/CONFIG.TOML

Configuration

# resolution order:
./aphrodite.toml then ~/.hermes/aphrodite/aphrodite.toml
# precedence:
env var > TOML > default
[compression]
auto_reload = false # opt-in
[flow]
budget_chars = 2600 # hard cap per turn
TEMPLATE IN THE REPO: aphrodite.toml.example

Keys not yet wired into the runtime are annotated DOCUMENTED BUT UNWIRED in the example file - the example is the source of truth.
